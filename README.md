# Klab-Mlab

研究室で GitHub を使い始める人は、まず学習用リポジトリへどうぞ。

## はじめに読むもの

- **[learn_github](https://github.com/Klab-Mlab/learn_github)** — GitHub の使い方を1回通しで学ぶための演習リポジトリです。SSH鍵登録・clone・branch作成・commit・push・Pull Request・レビュー・mergeまでを体験できます。初めての人は必ずここから始めてください。
- **[personal_research_repo_template](https://github.com/Klab-Mlab/personal_research_repo_template)** — 個人の研究テーマ用リポジトリを作るときのテンプレートです。`learn_github` を終えたら、研究テーマごとにこのテンプレートから新しいリポジトリを作成してください（例: `humanoid-motor-codesign` のようにテーマ名で命名し、`your-name` のような個人名では作らないでください）。

## 運用の考え方

- 研究用リポジトリはこの Organization（`Klab-Mlab`）の下に作成し、個人アカウントの private repo には置きません。卒業時の引き継ぎやアクセス権管理がしやすくなります。
- commit・push だけで終わらせず、Pull Request と Issue も使います。特に Issue は「議論したいこと」「意思決定の記録」として使うので、meetingの前に立てる習慣をつけてください。

質問があれば研究室Slack・meetingで聞いてください。
